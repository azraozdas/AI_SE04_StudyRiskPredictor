# System Design

## Architecture Overview

The AI Study Risk Predictor follows a modular system architecture:

1. Data Layer
- Raw academic dataset
- Cleaned dataset

2. Preprocessing Layer
- Missing value checking
- Encoding categorical features
- Data transformation

3. Machine Learning Layer
- Random Forest classifier
- Model training
- Risk prediction generation

4. Frontend Layer
- Streamlit dashboard
- Interactive input forms
- Visualization pages

5. Output Layer
- Prediction results
- Recommendations
- Charts and tables

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib
- Plotly

## Workflow

Student Input → Dataset Processing → Preprocessing → ML Prediction → Recommendation Output
